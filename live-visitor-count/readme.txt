Project: Live Visitor Counter

This is the simplest project that teaches WebSockets properly.

Imagine:

You open:

localhost:3000

in Chrome.

Page shows:

Visitors Online: 1

Open another tab:

Visitors Online: 2

Open another:

Visitors Online: 3

Close one:

Visitors Online: 2

Updates instantly without refreshing.

This teaches:

✅ Connection

✅ Disconnection

✅ Broadcasting

✅ Server → Client messages

which are the core concepts of WebSockets.
